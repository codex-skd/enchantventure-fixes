<h1 align="center">🛠️ EnchantVenture Fixes</h1>

<p align="center"><strong>Data fixes for the EnchantVenture modpack — server-side datapack, drop-in install.</strong></p>

<br>

---

<br>

<h2>✨ Overview</h2>

<p>EnchantVenture Fixes is a server-side datapack for Minecraft 26.2 that patches broken recipes, advancements, loot tables and predicates in the EnchantVenture modpack — without touching the mods themselves.</p>

<br>

<h2>🎯 Fixes included</h2>

<h3>🔧 tntfoundry</h3>
<p>Advancements fixed so single item entries are valid arrays: <code>hollow</code>, <code>paperwork</code>, <code>precision</code>, <code>remote_work</code>, <code>the_big_one</code>, <code>full_catalogue</code>.</p>

<h3>🏰 formationsoverworld</h3>
<p>Smithing loot tables for <code>stone_tower</code> and <code>witch_tower</code> now grant <code>minecraft:iron_ingot</code> instead of the broken <code>minecraft:chain</code> entry.</p>

<h3>🌙 fokus</h3>
<p>Added <code>is_night</code> predicate (time check, overworld, night hours) used by gameplay triggers.</p>

<h3>🐾 nerospace</h3>
<p>Added the <code>guide/new_life</code> advancement to breed the new creatures (<code>ember_strutter</code>, <code>meadow_loper</code>, <code>woolly_drift</code>).</p>

<h3>📦 nerologistics</h3>
<p>Restored a working recipe for the <code>configurator</code> item.</p>

<br>

<h2>📥 Installation</h2>

<ol>
<li>Download <code>EnchantVenture_fixes-&lt;version&gt;.zip</code>.</li>
<li>Place it in <code>world/datapacks/</code> (or <code>saves/&lt;world&gt;/datapacks/</code>).</li>
<li>Load the world — the fixes apply automatically. No config, no restart required.</li>
</ol>
