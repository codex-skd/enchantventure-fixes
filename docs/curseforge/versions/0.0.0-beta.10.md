<h2>v0.0.0-beta.10 - Marsward Field Manual translation; tntfoundry cleanup</h2>

<h3>Added</h3>
<ul>
<li><strong>marsward</strong>: full <code>es_ES</code> translation of the in-game Field Manual (<code>data/marsward/field_manual/field_manual.json</code>, 18 chapters). The manual's text is hardcoded into the mod's own datapack JSON rather than a <code>lang/</code> file, so a resource pack cannot translate it — this datapack overrides the file entirely with the Spanish version.</li>
</ul>

<h3>Removed</h3>
<ul>
<li><strong>tntfoundry</strong> advancement fixes (<code>hollow</code>, <code>paperwork</code>, <code>precision</code>, <code>remote_work</code>, <code>the_big_one</code>, <code>full_catalogue</code>): the mod is no longer present in the EnchantVenture modpack, so these fixes were dead weight (and were breaking the build, which reads the mod JAR to generate them).</li>
</ul>
