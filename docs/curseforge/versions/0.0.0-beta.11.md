<h2>v0.0.0-beta.11 - Recipe/advancement fixes; Equivalent Legacy EMC; NeroAgriculture tags; Better Villager Animations book</h2>

<h3>Fixed</h3>
<ul>
<li><strong>frontier_armaments</strong>: 5 shaped recipes using invalid <code>minecraft:chain</code> ingredient key — replaced with <code>minecraft:iron_ingot</code> (juggernaut helmet/chestplate/leggings/boots, peasant chestplate).</li>
<li><strong>nerologistics</strong> & <strong>nerotech</strong>: configurator recipes now included (upstream had no <code>tools</code> ingredient, so no fix needed; recipe stubs added).</li>
<li><strong>bosscraft_2</strong>: 7 advancements (<code>burn_advandement</code>, <code>dead_advancement</code>, <code>dust_advancement</code>, <code>exterminator_advancement</code>, <code>ice_advancement</code>, <code>mountain_advancement</code>, <code>ninja_advancement</code>) using non-existent <code>entity_sub_predicate_type</code> registry — replaced with direct entity type predicates.</li>
<li><strong>aerialhell</strong>: shroomboom loot table <code>entity_properties</code> condition with tag <code>#minecraft:skeletons</code> — replaced with <code>entity_type</code> condition listing 4 skeleton variants (<code>skeleton</code>, <code>wither_skeleton</code>, <code>stray</code>, <code>bogged</code>).</li>
</ul>

<h3>Added</h3>
<ul>
<li><strong>equivalent_legacy</strong>: EMC values for <code>occultism:silver_ingot</code> (512), <code>occultism:silver_nugget</code> (57), <code>ecologics:azalea_flower</code> (32), <code>reliquary:witch_hat</code> (30) — prevents "EMC Exploit" warnings on server startup.</li>
<li><strong>neroagriculture</strong>: 32 material tags under <code>c:</code> namespace (dusts, gems, ingots, ores, raw_materials) with fallback items where mods provide them — resolves "material tag is empty" warnings.</li>
<li><strong>bettervillageranimations</strong>: in-game guide book (<code>data/bettervillageranimations/book/guide.json</code>) with basic info on new villager animations and interactions.</li>
</ul>

<h3>Removed</h3>
<ul>
<li><strong>ancient_artifacts</strong>: function fixes (<code>knockback/loop</code>, <code>recycling_crystal/tag_arrow</code>) — mod is no longer installed in the pack.</li>
</ul>

<h3>Maintained</h3>
<ul>
<li><strong>marsward</strong>: full <code>es_ES</code> Field Manual translation (18 chapters).</li>
<li><strong>formationsoverworld</strong>, <strong>fokus</strong>, <strong>nerospace</strong>, <strong>the_lost_city</strong>, <strong>berezka_api</strong>: existing loot tables, predicates, template pools, Lootr stub.</li>
</ul>
