<h2>v0.0.0-beta.6 - berezka_api chest loot tables</h2>

<h3>Added</h3>
<ul>
<li><strong>berezka_api</strong>: reintroduced all 6 chest loot tables (<code>chests/car</code>, <code>farm</code>, <code>store</code>, <code>diningroom</code>, <code>treasure</code>, <code>berezkahousesmall_0</code>). The mod's built-in datapack (<code>berezka_api_data</code>) never registers: <code>openPrimary()</code> throws a <code>NullPointerException</code> while building the pack's metadata (the icon array is <code>null</code>), so every <code>berezka_api:chests/*</code> chest failed to load loot, confirmed by Lootr errors (<code>couldn't be resolved</code>) at multiple world positions. Item lists were recovered from string constants embedded in <code>BuiltInResourcePack.class</code>; quantities are a reasonable approximation except <code>treasure.json</code>, recovered verbatim with its real values.</li>
</ul>
