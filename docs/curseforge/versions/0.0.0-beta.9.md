<h2>v0.0.0-beta.9 - Ancient Artifacts 2 enchantment NBT fix</h2>

<h3>Fixed</h3>
<ul>
<li><strong>ancient_artifacts</strong>: <code>utilities/knockback/loop</code> used the old-format enchantments component NBT shape (<code>components: {enchantments: {"ancient_artifacts:knockback": 1}}</code>). In 26.2 the <code>minecraft:enchantments</code> item component value is <code>{"levels": {...}}</code>, so the armor_stand <code>summon</code> errored every time combo boots triggered a dash (reached from <code>tick</code>). Fixed to <code>{"minecraft:enchantments": {"levels": {"ancient_artifacts:knockback": 1}}}</code>.</li>
<li><strong>ancient_artifacts</strong>: <code>recycling_crystal/tag_arrow</code> used the same old shape as an NBT match, so the infinity/multishot detection never matched (arrows were always tagged <code>no_infinity</code>/<code>no_multishot</code>). Updated to the 26.2 <code>{"levels": {...}}</code> format.</li>
</ul>
